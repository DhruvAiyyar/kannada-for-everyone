# Kannada for Everyone

Interactive platform to learn practical Kannada through everyday situations
(greetings, shopping, transport, healthcare, workplace), with audio, progress
tracking and quizzes.

## Run locally
Open `index.html` in a browser. No build step or dependencies.

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. Go to vercel.com, click "Add New > Project", and import the repo.
3. Framework Preset: "Other". Leave build command and output directory empty.
4. Click Deploy.

(Or drag-and-drop the folder at vercel.com/new, or run `npx vercel` inside it.)
